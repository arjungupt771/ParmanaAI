🧠 Parmana AI — How the System Works (Elaborate Explanation)

Parmana AI is a hallucination-aware medical question answering and evaluation framework.
Its core philosophy is simple but powerful:

An answer is only as good as the evidence that supports it.

Instead of focusing on fluency, Parmana AI focuses on grounded correctness.

1️⃣ Input Stage — User Question

The pipeline starts with a raw natural-language question, e.g.:

“What are the symptoms of fever?”

“Does diabetes increase cardiovascular risk?”

At this point, the system makes no assumptions and does not generate an answer immediately.

2️⃣ Mode Classification — FACTUAL vs INFERENTIAL

The first decision Parmana AI makes is:

What kind of reasoning does this question require?

🔹 FACTUAL Mode

Triggered when the question asks for:

definitions

symptoms

treatments

dosages

side effects

Example:

“Symptoms of fever”

These require authoritative, guideline-level evidence.

🔹 INFERENTIAL Mode

Triggered when the question asks about:

associations

risks

effects

evidence from studies

Example:

“Does diabetes increase cardiovascular risk?”

These require research evidence, not definitive claims.

📌 This separation is critical.
Most hallucinations happen when systems mix these two modes.

3️⃣ Evidence Retrieval — Before Generation (Key Design Choice)

Unlike standard LLM pipelines, Parmana AI retrieves evidence before generating an answer.

🔹 FACTUAL Mode → Trusted Guidelines

WHO guidelines

ICMR guidelines

Curated authoritative sources

If no guideline evidence exists, the system refuses to answer safely.

This is intentional and medically correct.

🔹 INFERENTIAL Mode → Research Abstracts

PubMed-style abstracts

Association-level evidence

Non-causal, cautious sources

If no relevant research evidence exists, the system again refuses safely.

📌 PubMedQA is NOT used here
It is reserved strictly for offline evaluation, not live answering.

4️⃣ Evidence-Gated Answer Generation

Only after evidence is available, the system proceeds to generation.

🔹 How Generation Works

The retrieved evidence is embedded directly into the prompt

The generator is instructed to:

use only the provided evidence

avoid adding external knowledge

use cautious language for inferential answers

If an LLM (Groq) is available → it is used
If not → a deterministic evidence-based fallback is used

📌 This ensures:

reproducibility

safety

no hallucinated facts

5️⃣ Claim Extraction — Sentence-Level Decomposition

The generated answer is not treated as a single block.

Instead, Parmana AI:

splits the answer into individual factual claims

ignores very short or vague fragments

applies stricter filtering in inferential mode

Example answer:

“Fever causes chills and sweating.”

Becomes:

Claim 1: Fever causes chills

Claim 2: Fever causes sweating

This enables fine-grained verification.

6️⃣ Deterministic Claim Verification (No LLM Self-Judging)

Each extracted claim is verified independently against the retrieved evidence.

🔹 Verification Method

Lexical overlap

Evidence presence

Conservative thresholds

No LLM critic involved

Each claim receives a verdict:

SUPPORTED

PARTIALLY_SUPPORTED

INSUFFICIENT_EVIDENCE

NO_EVIDENCE_PROVIDED

📌 This makes verification:

transparent

auditable

reproducible

Unlike LLM-based critics, the system does not judge itself.

7️⃣ Hallucination Scoring — Claim-Level, Not Answer-Level

Instead of saying “this answer is hallucinated”, Parmana AI computes a hallucination score based on:

number of claims

type of verdict per claim

severity of unsupported assertions

🔹 Interpretation

0.0 → fully grounded

>0.2 → high hallucination risk

This allows:

nuanced analysis

partial correctness recognition

fair penalization

8️⃣ Relevance Scoring — Did the Answer Address the Question?

In parallel, the system computes a relevance score:

Measures semantic overlap between question and answer

Penalizes off-topic or evasive responses

Returns a value between 0 and 1

This prevents systems from scoring well by:

being safe but irrelevant

refusing unnecessarily

9️⃣ Safe Refusal as a First-Class Outcome

If no evidence exists, Parmana AI does not hallucinate.

Instead, it returns:

a safe refusal

zero hallucination score

clear system status

📌 This is treated as success, not failure.

In medical AI, knowing when not to answer is a strength.
